## 🚀 Projeto em destaque

### 📋 Projeto Orçamento

Aplicativo mobile desenvolvido em **React Native, Expo e TypeScript** para
criação e gerenciamento de orçamentos.

Principais funcionalidades:

- 👤 Cadastro de clientes
- 📝 Criação e gerenciamento de orçamentos
- 🛠️ Inclusão de múltiplos serviços
- 🧮 Cálculo automático de valores
- 💰 Aplicação de descontos
- 🔄 Controle de status
- 💾 Persistência local dos dados
- 📄 Geração de orçamento em PDF
- 📤 Compartilhamento do PDF

👉 [Ver Projeto Orçamento](https://github.com/NandoAmadoDev/projeto-orcamento)
