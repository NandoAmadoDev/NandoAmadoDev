### 🎯 Targets — Gestão de Metas Financeiras

Aplicativo mobile desenvolvido em **React Native, Expo, TypeScript e SQLite**, durante minha formação em desenvolvimento mobile pela Rocketseat.

O projeto permite organizar objetivos financeiros, acompanhar o progresso das metas e registrar movimentações, utilizando um banco de dados local.

**Principais funcionalidades:**

- 🎯 Cadastro e gerenciamento de metas financeiras
- ✏️ Edição de metas cadastradas
- 💰 Registro de entradas e saídas
- 📊 Acompanhamento do progresso de cada meta
- 🧮 Cálculo de valores acumulados e percentuais
- 📋 Histórico de transações financeiras
- 💾 Persistência local utilizando SQLite
- 🧭 Navegação entre telas com Expo Router
- ✅ Validação de formulários e valores monetários
- 📱 Interface desenvolvida com componentes reutilizáveis

**Tecnologias:** React Native • Expo • TypeScript • SQLite • Expo Router

👉 **[Ver Projeto Targets no GitHub](https://github.com/NandoAmadoDev/target-react-native)**
